# 一轮竞赛讲义：编译与使用

## 阅读与封面

`高中物理竞赛一轮讲义_董兴习.pdf` 为本次合订本，含32章、附录E和高阶A1—A6，共765道例题。封面为“高中物理竞赛一轮讲义”，署名董兴习、合肥一六八中学、19719272621，不印日期或“终审版”。

本次针对《全书只读检查报告》继续补充知识讲解、证明桥梁和解答步骤，并调整内容过少的章末尾页。报告中的页码对应修改前1342页版本，修改后的定位见《修订与验收报告》。正常章末留白仍然保留。

## 编辑与编译

解压 `一轮竞赛讲义_可编辑源码与TikZ.zip`，进入：

```text
physics-competition-first-round/sample/xes-original/restructured-complete
```

运行：

```sh
mkdir -p build/local
xelatex -interaction=nonstopmode -halt-on-error -file-line-error -recorder -output-directory=build/local main.tex
xelatex -interaction=nonstopmode -halt-on-error -file-line-error -recorder -output-directory=build/local main.tex
```

如日志提示交叉引用改变，再运行一遍。输出为 `build/local/main.pdf`。本次使用 TeX Live 2026 的 XeLaTeX，需要中文、TikZ、PGFPlots、tcolorbox 等宏包，中文字体由 ctex 按平台选择。

当前正文位于 `generated/chapters/`，附录位于 `generated/appendices/`，高阶部分位于 `advanced/`。本次27个独立增补片段和29幅新增 TikZ 集中在 `chapters/completeness-20261024/`；原有题图、解图和图号引用保留。记号与单位说明移至阅读指南。

直接编辑当前 TeX 即可编译，无需运行历史讲次生成器。为防止日后覆盖重放丢失修改，请同步维护 `tools/quality_completeness_*.py`。它们由 `tools/apply_final_review.py` 在历史修订层之后应用，入口 `tools/apply_quality_revision.py` 会依次重放所有修订层。

## 核验记录

仓库根目录 `audit/completeness_20261024/` 保存本次逐项处理说明和检查数据：

- `source-review.json`：765题的题图、解答图、图文引用结构检查。
- `figure-reference-review.json`：实际图号计数器和引用锚点检查。
- `pdf-review.json`：空白页、稀疏页候选、越界文字、孤悬解答标题检查。
- `physics-checks.json`：原有37项公式检查；`checks/` 另存本次补充推导的独立核算与分区记录。
- `compile-and-portability.json`：最终编译、覆盖重放及独立目录复编核对。
- `交付清单.json`：本次 PDF、源码包和说明文件的 SHA256。

源码包包含活动 TeX、可编辑 TikZ 和编译记录实际使用的本地媒体依赖，不包含历史发布 PDF、Git LFS 对象库或本机构建缓存。各类自动检查及抽查的范围和限制以验收报告为准。
