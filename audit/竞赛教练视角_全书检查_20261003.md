# 竞赛教练视角：全书检查与修改建议

检查日期：2026-10-03。

**总体判断：现稿可以作为教练备课和授课的理论底稿。若要交给学生作为一轮主教材，还需要补齐基础专题、学习层级和独立训练。** 部分高阶理论的展开已经很深，但不能据此认定学生学完就具备决赛或金牌水平；这一目标还需要陌生情境迁移、限时作答、实验和持续反馈。

## 检查对象、方法与边界

- 对象：当前正式《高中物理竞赛一轮讲义》合订本，1106个PDF页面；32章正文占902页，另有附录、高阶选读及末尾索引页。
- PDF SHA-256：`bc2f0c177b55139f76811fbce85d9d82d76fe04b15d4a71135373b487c710062`。
- 全书结构检查：32章的章、节、子节目录，例题与解答入口，以及附录、高阶选读和书末索引；核对现用书稿和正式PDF目录。
- 内容抽核：重点阅读第7、9—11、16、18、20、25、28、31、32章的代表性推导或解答；检查其他章的结构与专题分布，高阶选读检查代表性段落。本次没有逐题独立重解575道正文例题，也没有逐页语义审完1106页。
- 九项代表性数值或关系复算，结果均与书中表达及印刷舍入一致；它们只能支持相应条目的判断。
- 实际查看15个不同PDF页面的渲染：10、348、359、360、365、530、590、755、756、823、899、909、910、911、1106；899页另作高清复看。抽看页未发现可确证的遮字、裁切或图文重叠，不能外推为全书版式验收。
- 比较基准包括官网公布的[《全国中学生物理竞赛内容提要（2015年修订）》](https://cpho.pku.edu.cn/info/1033/1042.htm)。这里只把这一明确版本作为覆盖与分层参考，没有宣称完成2026年度全部竞赛文件的核验。
- 以下“PDF页”指阅读器页序；32章正文的书内页码为PDF页序减9。

## 值得保留的教学基础

1. **主要理论框架已经建立。** 数学工具、运动学、动力学、热学、电磁学、光学和近代物理都有独立章节。32章共575个例题框和575个解答入口。入口数量相等仅说明结构对应，不代表每份解答都已正确性验收。
2. **有些解答已包含好的建模习惯。** 例如10.5先检查启动，再识别中途停滑并切换方程；20.4区分孤立带电球与接地球；25.4区分精确带宽关系和弱损耗近似；25.5区分相位谐振与幅值极值。这些内容有助于克服公式套用。
3. **部分图文配合清楚。** 例10.5的初态与两阶段运动图区分明确；28.5用中间像连接两级成像，并说明虚物的有向物距；32.12的子核峰值图与解析结果一致。应保留题图、分析图和模型条件之间的对应。
4. **量纲、极限和可行性检验已多处出现。** 下一步应将它们整理为学生能反复使用的检查清单，并要求学生在独立习题中实际完成。

## 优先修改项

这里的P1表示会明显影响一轮训练成效，P2表示影响使用、定位或编辑一致性；不把教学问题冒称为物理公式硬错。本次抽核没有确认新的P0级公式错误，也没有据此作全书无错结论。

### P1-1：先补基础覆盖缺口

**证据。** 检查32章、附录和高阶选读的目录与相关段落，并对相关术语作全文定位：

- 第20、21章提及半导体、电子和空穴，但没有形成p型/n型、PN结、半导体二极管及其导电特性的系统讲解。
- 第21章提及电解液载流子，但未找到法拉第电解定律及电解定量计算的完整教学单元。
- 第29章等处使用激光解释相干性，第26、30章有激光束计算；第32章未形成受激辐射、粒子数反转和激光产生机制的讲解。
- 整流只在发电机换向器语境中出现；未找到整流—滤波—稳压的系统电路单元。三相交流及连接法也未形成独立讲解；三相点、三端电阻星三角变换不能替代这一专题。

这些内容在上述官网提要的相应部分有列项。不能仅凭没有命中关键词就认定完全不存在；这里的判断同时依据现稿相关章节的实际结构和上下文。也不能把半导体人物介绍、激光照明算例等视为已经教过相应机理。

**改法。** 在第21章之后安排“导电介质与电子器件”的基础单元，包含载流子、电解定律、PN结与器件特性；在第25章补整流、滤波、稳压及必要的三相连接；在第32章原子光谱之后补受激辐射与激光。先满足提要要求的定性或定量深度，再增加挑战题。配套基本题和辨析题，避免只增加几个定义。

### P1-2：缺少独立作答的训练闭环

**证据。** 32章正文有575个例题框与575个解答入口，但没有独立的章末习题栏目、分层练习及统一的达标检查。学生可以阅读许多答案，却缺少在不看答案时暴露问题的固定环节。项目已有测试文件，不等于本书已有逐章训练闭环。

**改法。** 每章建立“示范例题—独立练习—变式迁移—限时检查—订正复练”。新增课后习题从额外资料中筛选，按物理模型和解题路径与正文、高阶选读去重。初步每章8—12题，随章节容量调整，不为凑题量保留换数值的重复题。题目放在章末，提示、答案和完整解答分开；完整解答保留条件检验。

建议基础、方法应用、综合题约为4∶4∶2，但最终根据具体题目的解题负担调整。每道题写清训练目标和前置知识，而不只标难度星级。

### P1-3：深度层级与“一轮”名称尚不匹配

**证据。** 第10章共36页，其中10.5—10.7的多自由度、非线性和格波选读约占PDF344—358的15页，之后才进入综合例题。选读标题已经存在，问题是没有提供明确跳读路径与对应练习。第18章18.2.1、18.2.2展开条件熵、互信息、连续分布和最大熵（PDF530—531），这些子节没有明确选读标记。高阶A4还有Klein–Gordon场与局域规范对称性；它虽已在高阶卷中，仍需要说明阅读前置与用途。

**改法。** 给全书建立统一的“基础必修、复赛提高、决赛拓展、理论选读”标记；标记是教学建议，涉及竞赛范围时须注明所依据的文件版本。每章首列必读节、选读节、先修知识与需要掌握的例题。第10章允许读完10.1—10.4后先做常规振动训练；多自由度及格波按目标选学。第18章的信息论证明移为选读或明确标记。A4的场论推导安排在相关数学、分析力学和相对论之后。

高级内容可以保留，但不应让学生误以为掌握全部高级定义是完成一轮的必要条件。

### P1-4：需要补足实验与数据训练，或明确理论书的使用边界

**证据。** 书中有光电效应直线数据、测量加载、干涉测距等例子，也有零散误差说明；尚未形成仪器读数、数据处理、误差或不确定度、方案设计与操作记录的系统训练单元。只有情景图与实验原理介绍，无法检验学生是否会实际操作、处理数据和解释异常。

物理竞赛的复赛和决赛包含实验，见[官方竞赛简介](https://cpho.pku.edu.cn/info/1070/1207.htm)。本报告不引用其中可能已变化的分值、名额等细节。

**改法。** 若本书定位为理论讲义，应在使用说明中明确配套实验教材和训练安排。若目标是完整竞赛培养体系，另设实验与数据训练分册：测量与记录、作图与拟合、误差分析、方案选择、典型实验和限时操作。纸上数据题是准备环节，仍需实际器材训练。

### P2-1：方法散落在长解答中，缺少可迁移的归纳

**证据。** 第7章已经解释系统选择、外冲量量级与动量通量；第10、20、25章也有条件检查，但未形成统一的章首目标、章末方法总结及诊断题。学生容易记住某道题的推导，遇到换情境后不知道该从哪里开始。

**改法。** 每节或每章总结“触发条件—对象与参考系—主方程—约束条件—终止/分段条件—验算”。例如：

- 10.5：弹力与静摩擦比较 → 两体方程 → 质心/相对运动 → 首次停滑 → 检查能否保持静止 → 单体后续运动 → 摩擦功核验。
- 20.4：先辨接地或孤立 → 检查等势与总电荷 → 确定像电荷 → 计算真实电荷受力 → 判断符号区间。受力计算和组装能的二分之一系数不能混用。
- 25.5：先辨问题问同相还是问幅值极值 → 写导纳 → 相位条件 → 正实频率条件 → 损耗极限核验。

归纳之后配一个不直接给方法名称的迁移题，检验学生能否自主选择。

### P2-2：例题难度与前置知识需要显式标注

**证据。** 第1章起始两例分别涉及单摆和黏性流体终端速度（PDF10）。量纲分析的示范很好，但刚入门者还需要知道哪些物理关系由题目给定，哪些属于以后要学习的背景。第10章综合例题又包括变质量软链、恒速/自由轴调速器和球面电荷简正模；这些题的前置知识负担差别很大，现有例号不能表达层次。

**改法。** 给例题标教学层级及前置知识。第1章把流体例注明为给定模型的工具练习，必要时加“现在只使用题给阻力关系”的短说明。10.5作为分段建模训练，10.6—10.10按目标分组；用单摆、复摆、普通耦合振子等阶梯练习连接到复杂模型。将题干的可行性条件前移，例如10.8中保持杆长为正的限制已在解答中解释，可在题干的模型说明中一并交代。

### P2-3：重复专题应明确分工

**证据。** 第9章已经推导有心力轨道、有效势、Binet方程及开普勒关系，第11章再次系统推导相应内容。这可以用于递进教学，但目前没有章首说明两次讲解分别负责什么。第9章使用“比内方程”，第11章使用“比耐方程”，同一英文术语存在译名不一致。

**改法。** 第9章主线放在角动量、参考点、刚体与滚动；天体运动保留应用入口。第11章主线放在有效势、运动分支、二体问题和轨道变化，以前章已得的结论作明确引用。保留必要复习，减少重复长推导，并统一术语。

### P2-4：第31、32章例号未按出现顺序递增

**成书证据。**

- 第31章PDF893出现31.7，PDF895随后出现31.6。
- 第32章按阅读顺序为：32.5、32.1、32.6、32.7、32.2、32.8、32.3、32.9、32.10、32.11、32.4、32.12。
- PDF909同页先出现32.11“氘氚聚变的Q值”，后出现32.4“经过三个半衰期的剩余量”。

这些例号可以各自唯一，却仍影响课堂口令、作业指定、习题关联和索引查找。

**改法。** 统一按现行章节阅读顺序编号；保留内部来源标识，更新正文交叉引用、目录或清单和独立章节PDF。全书补习题时还需核对新增题目没有使引用指向别的题。

### P2-5：“符号与常数索引”尚未完成

**证据。** 最后一页PDF1106（书内1097）只有单位制、矢量/微分/虚数记号和编号规则的简短说明，没有符号条目、常数表或页码索引。全书内也混用粗体矢量与带箭头矢量，所以该页的统一记号声明不完全对应现稿。

**改法。** 建立常用物理常数表、主要符号及同符号不同语境表，增加关键概念和方法的页码定位。尤其说明K/k、I、L、M、Q、n等的多种用途；只需局部明确，不必强求全书每个符号只代表一种量。统一矢量记号或在使用说明中承认约定。若暂不做实际索引，先将标题改为与现有内容相符的“记号说明”。

## 建议实施顺序与验收方式

**第一步：完成覆盖与层级表。** 明确基础缺口的插入位置；给32章列必读、提高和选读内容。验收时用章节、例题、习题与前置知识对应表检查，不能只看是否出现关键词。

**第二步：用第7章做课后习题样稿。** 从额外资料选8—12题，覆盖系统选择、冲量、变质量和碰撞；正文例题作参考，不重复拿来充当作业。提供分开的题目、提示、解答，以及失分原因分类。

**第三步：推广逐章训练，修复例号和索引。** 同步核对章节版、分卷版与合订本。最后补跨章节陌生模型题和限时训练；每份测试有预设训练目标与评分点。

**第四步：建立实际反馈。** 有条件时安排学生试用：先独立作答，再记录建模错误、条件遗漏、计算错误和时间分配。教师据真实作答调整难度与题量。没有这些数据时，本报告不对金牌概率或培养效果给百分比。
